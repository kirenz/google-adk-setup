3  title: “macOS — Python 3.11 via python.org”

This path relies only on the official Python installer. No Homebrew or third-party package managers are required.

3.1 Step 1. Download the Installer

  1. Open your browser to the official Python 3.11 release page: https://www.python.org/downloads/release/python-3110/
  2. Scroll to Files and download the macOS 64-bit universal2 installer (.pkg).

Save the installer in your Downloads folder so you can remove it once the installation succeeds.

3.2 Step 2. Run the Installer

  1. Double-click the downloaded .pkg.
  2. Accept the license and proceed with the default options.
  3. When prompted for admin approval, enter your password to allow the installation.

If macOS blocks the installer, right-click the .pkg, choose Open, then click Open again to bypass Gatekeeper for this trusted package.

3.3 Step 3. Verify the Installation

Open Terminal (Launchpad → search for “Terminal”) and run the following checks.

Confirm that Python 3.11 is reachable from the command line: 
python3.11 --version
Confirm that pip is installed with the same interpreter: 
pip3.11 --version

Expect outputs similar to Python 3.11.x and pip 24.x. If you see another version, retry the installer and ensure you launched the newly installed Terminal session.

3.4 Step 4. Create a Convenience Alias (Optional)

If the commands above work but you prefer to type python instead of python3.11, create a shell alias.

Open your shell profile in the default text editor: 
open -e ~/.zprofile

Add this line at the end of the file, then save and close:

alias python="python3.11"
alias pip="pip3.11"
Reload the profile so the alias is available immediately: 
source ~/.zprofile

The alias only affects new Terminal sessions. If you run automated scripts later, call python3.11 explicitly to avoid ambiguity.

3.5 Step 5. Record the Installation Path

Knowing where Python lives helps when configuring IDEs.

Print the full path to the Python 3.11 executable: 
which python3.11

Take note of the path (usually /usr/local/bin/python3.11). You will reference it when creating virtual environments.

Once the checks pass, move on to Virtual Environment and pip.
